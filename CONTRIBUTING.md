# Contributing to 7 Days of AI Security

## What we want

- Dead link fixes and more current primary sources for any of the 7 days.
- Translations of the day list into other languages.

## What we don't want

- New days — this repo is deliberately fixed at 7. If you want more depth, that's what [30 Days](https://github.com/ppradyoth/30-days-of-ai-security) and [100 Days](https://github.com/ppradyoth/100-days-of-ai-security) are for.
- Promotional links without a personally-verified AI security use case.
- Unverifiable claims (no link, no CVE number, no paper).

## How to submit

1. Fork this repository.
2. Create a branch: `git checkout -b fix/day-N-description`.
3. Make the change, keeping the existing `- [ ] **Day N — Title.** ...` format.
4. Open a PR explaining what was wrong and what you changed it to.

## Questions

Open an issue. Keep it public and async so the answer helps the next person too.
